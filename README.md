# KJK Encryptor

把文件或文件夹加密打包成 `.kjk` 加密包的工具，提供 **Windows 桌面版** 与 **网页版**。两端加密算法一致，互相同步互通；桌面版向下兼容 v1.0.1 / v1.0.2 / v1.0.3 全部历史格式。

- 项目版本：**v1.0.4**
- 官网：<https://dnteam.top>
- API 文档：<https://dnteam.top/KJK/api/api_docs.html>

***

## 一、下载与安装

| 项目   | 内容                                          |
| ---- | ------------------------------------------- |
| 运行系统 | Windows 7 及以上（建议 Windows 10 / 11，x86-64）    |
| 安装包  | `KJK-installer.exe`（或发布压缩包内同名安装器）           |
| 安装目录 | 默认 `C:\Program Files\KJK-Encryptor\`        |
| 引擎   | 加密引擎 DLL 位于安装目录 `engine\` 子目录，多版本共存，自动选用最新版 |
| 卸载   | 使用系统"卸载程序"里的 KJK Uninstaller                |

安装器会自动注册右键菜单（文件 / 文件夹 / `.kjk` 包）与 `.kjk` 文件关联。安装完成后即可直接使用，无需其它配置。

> 安装、卸载、注册右键菜单时若提示"需要管理员权限"，属正常现象，点击允许即可。

## 二、使用方式（桌面版）

### 1) 加密

任选一种方式：

- **主程序**：打开 `KJK-Encryptor` → 加密页 → 选择文件或文件夹 → 输入密码（可留空）→ 点击加密，生成 `.kjk` 包。
- **右键菜单**：对文件 / 文件夹点右键 → 「KJK Encryptor」→ 选择：
  - **加密到此文件夹**：在当前位置生成 `.kjk`
  - **加密到…**：选择保存位置后生成 `.kjk`
  - **打包加密到…**：将文件 / 文件夹打包成 `.kjk`
- **拖放**：把文件 / 文件夹直接拖进主窗口即可加入加密列表。

### 2) 解密

- **双击** **`.kjk`**：输入密码 → 自动解压到文件夹并打开目录树，可直接预览 / 导出单个文件（内容按需读取）。
- **右键** **`.kjk`**：选择「解密到这里」或「解密到…」。
- **主程序解密页**：点击"选择文件"或粘贴密文 → 输入密码 → 解密。

### 3) 目录树（包管理器）

打开 `.kjk` 后进入目录树窗口，支持与资源管理器相近的操作：

| 操作                | 方式                      |
| ----------------- | ----------------------- |
| 添加文件 / 文件夹        | 拖入窗口（可拖到指定目录节点），或点击"添加" |
| 重命名 / 删除条目        | 选中条目后右键，或使用快捷键          |
| 修改密码 / 压缩 / 完整性校验 | 工具栏或右键菜单                |
| 导出条目              | 选中后拖出窗口，或点击"导出"         |
| 保存修改              | 点击"保存"（保存前目录树的改动会先提示确认） |

> 目录树有未保存改动时关闭窗口会弹出确认提示，避免误操作丢失修改。

## 三、使用方式（网页版）

- 直接打开 `index.html`（浏览器本地运行），或部署到任意静态服务器后访问。
- 支持：加密生成 `.kjk` / 密文；粘贴密文解密；打开 `.kjk` 后删除 / 重命名条目、修改密码、追加文件，编辑后自动保存新包。
- 网页版同样在本地处理数据，不上传文件内容。

> 网页版参与加密 / 解密的数据均在浏览器本地完成；如需局域网访问，可运行 `python file/www.py` 启动本地服务后再在浏览器中打开。

## 四、格式与兼容

| 版本              | 说明                                                              | 支持           |
| --------------- | --------------------------------------------------------------- | ------------ |
| KJKv9           | 二进制：64B 头 + 4MB 分块 AES-256-GCM + 加密目录（桌面版 C 引擎 / 网页版 WebCrypto） | 加密 + 解密 + 编辑 |
| KJKv8           | 分块 AES-256-GCM，大文件                                              | 加密 + 解密      |
| KJKv7           | 整条 AES-256-GCM                                                  | 加密 + 解密      |
| KJKv5 / v1 / 更早 | 旧文本格式（SHA-256 计数器模式）                                            | 仅解密（向后兼容）    |

- 桌面版 / 网页版会自动检测格式版本，无需手动选择。
- 打开旧格式包时，可将其**升级保存为 KJKv9**。
- 如需让新数据写成旧版兼容格式，可在软件设置里选择"格式兼容"模式。

## 五、注意事项

1. **密码无法找回。** 解密仅依赖密码派生的密钥，软件不存储、不记录、不上传密码；密码一旦丢失，数据将无法恢复。请妥善保管密码与原始备份。
2. **务必保留原文件备份。** 我们无法保障你的加密文件是否能够安全持续存储，建议在加密后创建备份。
3. **处理完全本地进行。** 软件不会把文件内容、密码或任何个人信息上传到网络。
4. **旧格式升级**：新旧格式会一同处理；在管理器中，我们会主动提示您是否升级算法，这对于存储安全性，加载速度方面都有好处。但是我们无法绝对确保每一次升级都能无损，建议在升级前解密旧文件并进行备份。
5. **多选文件右键**：右键菜单"加密到此文件夹 / 加密到…"一次处理一个被点击的文件；如需一次打包多个文件 / 文件夹，请使用"打包加密到…"，或先在主程序加密页加入多个目标再加密。
6. **大文件**：文件会自动分块处理，并支持断点续传（进度写在安装目录的 `.kjkprog` 临时文件）；中断后再次开始会从已完成分页继续。
⚠请注意!!!!!:若您使用固态硬盘不建议一次性在固态硬盘中加密大文件(大于硬盘总大小的50%以上)，这会加速固态硬盘寿命磨损。建议在机械硬盘中执行解密操作。
7. **占用说明**：加密 / 解密会在后台线程进行并实时显示进度；为其它程序预留了系统资源。
8. **杀毒软件**：安装包为 PyInstaller 打包，个别第三方环境可能误报；请从官网或官方发布渠道下载。若您从第三方渠道下载的程序出现杀毒软件提示，请务必谨慎，我们不会主动修改您的注册表信息，MBR信息，系统文件数据等。
9. **使用范围**：请将本工具用于合法用途，遵守所在地区对加密软件的规定。详情参见 服务条款 及 免责声明

## 六、从源码运行（开发）

环境要求：Python 3.8+（推荐 3.10+），Windows。

```bash
# 安装可选依赖（核心功能仅依赖标准库）
pip install -r python/requirements.txt

# 启动桌面版
python python/main.py

# 启动本地网页服务
python file/www.py
```

可选依赖说明：

- `argon2-cffi`：解密最早期（KJKv5）密码哈希所需。
- `numpy`：无 C 引擎时加速 token 编解码。
- `flask` / `requests` / `Pillow`：本地 API 服务与图片预览等增强功能。

## 七、构建安装包（开发）

```bash
# 第一步：构建主程序（onedir），自动尝试编译 C 引擎到 engine/kjkfast-<版本>.dll
python python/build.py

# 第二步：构建安装器 + 卸载器
python file/build.py
```

构建产物：

- `KJK-Encryptor/` —— 主程序目录（`KJK-Encryptor.exe` + `_internal/` + `engine/kjkfast-<版本>.dll` + `version.txt`）
- `KJK-Installer.exe` —— 安装器（自动检测已安装版本，支持升级 / 覆盖）
- `KJK-Uninstaller.exe` —— 独立卸载程序
- `KJK-Registry.exe` —— 右键菜单注册工具

> 主程序采用 onedir 多目录结构，历代引擎 DLL 以版本号命名存放于 `engine/`，可共存、独立更新；启动无需解压临时文件。

## 九、常见问题

**Q：网页版为什么打不开我桌面版加密的文件？**
A：两端算法需保持一致。请确认两端均为 v1.0.4 及以上版本；旧版本存在换行符（CRLF）解析差异，v1.0.4 已修复。

**Q：加密 / 解密大文件时卡住或"未响应"？**
A：v1.0.4 采用分块 + 流式处理，不会一次性载入整个文件。若仍异常，请确认安装的是最新版本，必要时重启后再试。

**Q：忘记密码，能否找回？**
A：不能。加密数据只依赖密码派生密钥，软件不存储密码，请务必保管好密码并保留原文件备份。

**Q：旧版加密的文件还能解密吗？**
A：可以。v1.0.4 自动识别并解密 v1.0.1 / v1.0.2 / v1.0.3 的 KJKv5 / v7 / v1 等格式。

**Q：右键菜单点了没反应 / 提示"未选中"？**
A：请确认已安装并注册了 v1.0.4（v1.0.4 修复了部分 Windows 11 下拉式级联菜单参数丢失问题）。若仍未生效，可在主程序"设置"里重新注册右键菜单。
