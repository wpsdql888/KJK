KJK Encryptor API Documentation

KJK Encryptor provides a local HTTP API server for programmatic encryption and decryption. The server runs entirely on your machine — no data is sent to any external service.

1. Introduction

What is the KJK API?

The KJK Encryptor API is a lightweight HTTP server built into the desktop application. It allows you to encrypt files, text, and decrypt .kjk packages programmatically from scripts, command-line tools, or other applications running on the same machine.

Key features:

  • Runs locally on 127.0.0.1 — no external network access required
  • Supports both binary and JSON request formats
  • Cross-platform compatible (Linux, macOS, Windows)
  • Optional password protection with PBKDF2/Argon2 hashing

KJK API 係咩?

KJK Encryptor API 係內嵌喺桌面應用程式入面嘅輕量級 HTTP 伺服器。佢畀你透過腳本、命令列工具或者喺同一部機上面行嘅其他程式,以編程方式加密檔案、文字同解密 .kjk 套件。

主要特點:

  • 喺 127.0.0.1 本地運行 — 唔需要外部網路存取
  • 支援 binary 同 JSON 兩種請求格式
  • 跨平台兼容 (Linux、macOS、Windows)
  • 可選密碼保護,使用 PBKDF2/Argon2 雜湊

KJK API 是什么?

KJK Encryptor API 是内嵌在桌面应用程序中的轻量级 HTTP 服务器。它允许您通过脚本、命令行工具或同一台机器上运行的其他程序,以编程方式加密文件、文本和解密 .kjk 包。

主要特点:

  • 在 127.0.0.1 本地运行 — 无需外部网络访问
  • 支持二进制和 JSON 两种请求格式
  • 跨平台兼容 (Linux、macOS、Windows)
  • 可选密码保护,使用 PBKDF2/Argon2 哈希

3. Quick Start

Before using the API, you must enable it in Settings → API Server in the KJK Encryptor app, or start it programmatically in Python:

使用 API 之前,您必須喺 KJK Encryptor 應用程式嘅 設定 → API 伺服器 啟用佢,或者喺 Python 度以編程方式啟動:

使用 API 之前,您必须在 KJK Encryptor 应用程序的 设置 → API 服务器 中启用它,或在 Python 中以编程方式启动:

# Python
from api_server import start_server
url = start_server(port=5000)  # returns http://127.0.0.1:5000

Default port is 5000. The server listens only on 127.0.0.1 (localhost) for security.

預設埠號係 5000。伺服器只會喺 127.0.0.1 (本機) 監聽,以確保安全。

默认端口为 5000。服务器仅在 127.0.0.1 (本机) 上监听,以确保安全。

Tip: Replace 127.0.0.1:5000 with your actual host and port if you changed the configuration.
提示: 如果您修改過設定,請將 127.0.0.1:5000 換成您實際嘅主機同埠號。
提示: 如果您修改过配置,请将 127.0.0.1:5000 替换为您实际的主机和端口。

4. Status Check

GET http://127.0.0.1:5000/status

Check whether the API server is running. Returns server name and version. No authentication required.

檢查 API 伺服器係咪運行緊。傳回伺服器名稱同版本。唔需要認證。

检查 API 服务器是否正在运行。返回服务器名称和版本。无需认证。

Request Headers

HeaderValueRequiredDescription
Content-Typeapplication/jsonOptionalRecommended but not strictly required for GET
User-AgentKJK-Client/1.0OptionalClient identifier for logging

Linux / macOS (bash + curl)

bash 
curl -X GET http://127.0.0.1:5000/status \
  -H "Content-Type: application/json" \
  -H "User-Agent: KJK-Client/1.0"

Windows (PowerShell)

powershell 
$headers = @{
    "Content-Type" = "application/json"
    "User-Agent"   = "KJK-Client/1.0"
}
Invoke-RestMethod -Uri "http://127.0.0.1:5000/status" `
    -Method GET `
    -Headers $headers

Response

json 
{
  "status": "ok",
  "name": "KJK Encryptor API",
  "version": "1.0.1"
}

5. Encrypt

POST http://127.0.0.1:5000/encrypt

Encrypt data and return a .kjk package. Supports two request formats: binary upload (recommended for files) and JSON (for text).

加密資料並傳回 .kjk 套件。支援兩種請求格式:二進位上傳 (檔案推薦) 同 JSON (文字用)。

加密数据并返回 .kjk 包。支持两种请求格式:二进制上传 (文件推荐) 和 JSON (用于文本)。

Request Headers

HeaderValueRequiredDescription
Content-Typeapplication/octet-stream or application/jsonRequiredDetermines how the body is parsed
User-AgentKJK-Client/1.0OptionalClient identifier for logging

Query Parameters

ParamTypeRequiredDescription
passwordstringOptionalPassword for encryption (empty = no password)
filenamestringOptionalOriginal filename (default: untitled)
extstringOptionalFile extension (default: txt)
formatstringOptionalResponse format: json or file download (default)

Example 1: Binary Upload (Recommended for Files)

Upload a file as raw binary. The response will be a .kjk file download.

以原始二進位上傳檔案。回應會係 .kjk 檔案下載。

以原始二进制上传文件。响应将是 .kjk 文件下载。

Linux / macOS

bash 
# Encrypt without password
curl -X POST http://127.0.0.1:5000/encrypt \
  --data-binary @myfile.txt \
  -H "Content-Type: application/octet-stream" \
  -H "User-Agent: KJK-Client/1.0" \
  -o encrypted.kjk

# Encrypt with password (URL-encoded)
curl -X POST "http://127.0.0.1:5000/encrypt?password=mypassword&filename=myfile&ext=txt" \
  --data-binary @myfile.txt \
  -H "Content-Type: application/octet-stream" \
  -H "User-Agent: KJK-Client/1.0" \
  -o encrypted.kjk

Windows (PowerShell)

powershell 
# Encrypt without password
$bytes = [System.IO.File]::ReadAllBytes("myfile.txt")
Invoke-RestMethod -Uri "http://127.0.0.1:5000/encrypt" `
    -Method POST `
    -ContentType "application/octet-stream" `
    -Headers @{ "User-Agent" = "KJK-Client/1.0" } `
    -Body $bytes `
    -OutFile "encrypted.kjk"

# Encrypt with password
$bytes = [System.IO.File]::ReadAllBytes("myfile.txt")
Invoke-RestMethod -Uri "http://127.0.0.1:5000/encrypt?password=mypassword&filename=myfile&ext=txt" `
    -Method POST `
    -ContentType "application/octet-stream" `
    -Headers @{ "User-Agent" = "KJK-Client/1.0" } `
    -Body $bytes `
    -OutFile "encrypted.kjk"

Example 2: JSON Format (For Text)

Send text data as JSON. Useful for short strings or when you want the ciphertext in the response.

以 JSON 格式傳送文字資料。適合短字串或者當您想喺回應中取得密文時使用。

以 JSON 格式发送文本数据。适合短字符串或当您想在响应中获取密文时使用。

Linux / macOS

bash 
curl -X POST "http://127.0.0.1:5000/encrypt?format=json" \
  -H "Content-Type: application/json" \
  -H "User-Agent: KJK-Client/1.0" \
  -d '{"data": "Hello World!", "password": "secret123"}'

Windows (PowerShell)

powershell 
$body = @{ data = "Hello World!"; password = "secret123" } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:5000/encrypt?format=json" `
    -Method POST `
    -ContentType "application/json" `
    -Headers @{ "User-Agent" = "KJK-Client/1.0" } `
    -Body $body

Response (format=json)

json 
{
  "ciphertext": "誷竊蛦唄咚...",
  "kjk": "KJKv5\n2\n..."
}
Note: When using password, the .kjk file will contain a password header entry. Each .kjk file uses a single password.
注意: 使用 password 時,.kjk 檔案會包含密碼頭條目。每個 .kjk 檔案只用一個密碼。
注意: 使用 password 时,.kjk 文件将包含密码头条目。每个 .kjk 文件只使用一个密码。

6. Decrypt

POST http://127.0.0.1:5000/decrypt

Decrypt a .kjk package and return the original file(s). Supports both binary upload and JSON request.

解密 .kjk 套件並傳回原始檔案。支援二進位上傳同 JSON 請求。

解密 .kjk 包并返回原始文件。支持二进制上传和 JSON 请求。

Request Headers

HeaderValueRequiredDescription
Content-Typeapplication/octet-stream or application/jsonRequiredDetermines request parsing
User-AgentKJK-Client/1.0OptionalClient identifier

Query Parameters

ParamTypeRequiredDescription
passwordstringOptionalPassword (required if the .kjk file is encrypted)
formatstringOptionalResponse format: json (all files) or file download (first file)

Example 1: Binary Upload (Decrypt File)

Upload the .kjk file as binary. Response is the decrypted file.

以二進位上傳 .kjk 檔案。回應係解密後嘅檔案。

以二进制上传 .kjk 文件。响应是解密后的文件。

Linux / macOS

bash 
# Decrypt without password
curl -X POST http://127.0.0.1:5000/decrypt \
  --data-binary @encrypted.kjk \
  -H "Content-Type: application/octet-stream" \
  -H "User-Agent: KJK-Client/1.0" \
  -o decrypted.txt

# Decrypt with password
curl -X POST "http://127.0.0.1:5000/decrypt?password=mypassword" \
  --data-binary @encrypted.kjk \
  -H "Content-Type: application/octet-stream" \
  -H "User-Agent: KJK-Client/1.0" \
  -o decrypted.txt

Windows (PowerShell)

powershell 
# Decrypt with password
$bytes = [System.IO.File]::ReadAllBytes("encrypted.kjk")
Invoke-RestMethod -Uri "http://127.0.0.1:5000/decrypt?password=mypassword" `
    -Method POST `
    -ContentType "application/octet-stream" `
    -Headers @{ "User-Agent" = "KJK-Client/1.0" } `
    -Body $bytes `
    -OutFile "decrypted.txt"

Example 2: JSON Format (Get All Files)

Send the .kjk content as JSON text. Response includes all files in the package.

以 JSON 文字格式傳送 .kjk 內容。回應包含套件入面所有檔案。

以 JSON 文本格式发送 .kjk 内容。响应包含包中的所有文件。

Linux / macOS

bash 
curl -X POST "http://127.0.0.1:5000/decrypt?password=mypassword&format=json" \
  -H "Content-Type: application/json" \
  -H "User-Agent: KJK-Client/1.0" \
  -d '{"kjk": "KJKv5\n2\n..."}'

Windows (PowerShell)

powershell 
$kjkContent = Get-Content "encrypted.kjk" -Raw
$body = @{ kjk = $kjkContent; password = "mypassword" } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:5000/decrypt?format=json" `
    -Method POST `
    -ContentType "application/json" `
    -Headers @{ "User-Agent" = "KJK-Client/1.0" } `
    -Body $body

Response (format=json)

json 
{
  "files": [
    {
      "name": "myfile.txt",
      "data": "Hello World!",
      "size": 12
    }
  ]
}
Important: If the .kjk file is encrypted, you must provide the correct password. A wrong password returns HTTP 401.
重要: 如果 .kjk 檔案有加密,您必須提供正確嘅 password。密碼錯誤會傳回 HTTP 401。
重要: 如果 .kjk 文件已加密,您必须提供正确的 password。密码错误将返回 HTTP 401。

7. Settings — Format Compatibility

GET POST http://127.0.0.1:5000/settings/compat-format

Get or set the format compatibility mode used when encrypting. The mode controls which legacy .kjk format the new package is written in, so old versions of the app can still open it.

取得或設定加密時使用嘅格式兼容模式。模式控制新套件以邊種舊版 .kjk 格式寫入,令舊版應用程式仍然可以開啟。

获取或设置加密时使用的格式兼容模式。该模式控制新包以哪种旧版 .kjk 格式写入,以便旧版应用仍可打开。

Query Parameters

ParamTypeRequiredDescription
formatstringOptionalPOST only. One of auto, KJKv7, KJKv5. Omit to read the current value.

Linux / macOS

bash 
# Read current setting
curl -X GET http://127.0.0.1:5000/settings/compat-format

# Set to KJKv7
curl -X POST http://127.0.0.1:5000/settings/compat-format \
  -H "Content-Type: application/json" \
  -d '{"format": "KJKv7"}'

Windows (PowerShell)

powershell 
# Read current setting
Invoke-RestMethod -Uri "http://127.0.0.1:5000/settings/compat-format" -Method GET

# Set to KJKv7
$body = @{ format = "KJKv7" } | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:5000/settings/compat-format" `
    -Method POST -ContentType "application/json" -Body $body

Response

json 
{
  "format": "auto",
  "options": ["auto", "KJKv7", "KJKv5"],
  "label": "Auto (自动检测)"
}

9. Package Management (KJKv9)

Manage .kjk packages on disk: list entries, append files, rename, delete, change the password, and verify integrity. All endpoints accept a JSON body and operate on the package file located at path on the local machine.

管理磁碟上嘅 .kjk 套件:列出條目、追加檔案、重新命名、刪除、修改密碼同驗證完整性。所有端點都接受 JSON 主體,並對本機 path 位置嘅套件檔案進行操作。

管理磁盘上的 .kjk 包:列出条目、追加文件、重命名、删除、修改密码和验证完整性。所有端点都接受 JSON 请求体,并对本机 path 位置的包文件进行操作。

Note: Package management endpoints only support the KJKv9 format. Legacy formats (KJKv5/KJKv7) must be converted or handled through /decrypt.
注意: 包管理端點只支援 KJKv9 格式。舊版格式 (KJKv5/KJKv7) 需要轉換,或者透過 /decrypt 處理。
注意: 包管理端点仅支持 KJKv9 格式。旧版格式 (KJKv5/KJKv7) 需要转换,或通过 /decrypt 处理。

9.1 Open Package — POST /package/open

POST http://127.0.0.1:5000/package/open

Open a KJKv9 package and return its entry list. Returns 401 if the package is password-protected and the password is missing or wrong.

開啟 KJKv9 套件並傳回條目清單。如果套件有密碼保護而密碼缺失或錯誤,會傳回 401。

打开 KJKv9 包并返回条目列表。如果包受密码保护而密码缺失或错误,将返回 401。

json

{
  "path": "C:\\data\\my.kjk",
  "password": "secret123"
}

# Response
{
  "format": "kjk9",
  "has_password": true,
  "files": [
    { "name": "docs/readme.txt", "size": 2048, "mtime": 1700000000 },

9.2 Append Files — POST /package/append

POST http://127.0.0.1:5000/package/append

Add files into the package and save immediately. Each item in files has a local src_path and an optional relpath (defaults to the file name). Returns the updated entry list.

將檔案加入套件並立即儲存。files 入面每一項都有本機 src_path 同可選嘅 relpath (預設係檔名)。傳回更新後嘅條目清單。

将文件加入包并立即保存。files 中每一项都有本地 src_path 和可选的 relpath (默认为文件名)。返回更新后的条目列表。

json

  "files": [
    { "src_path": "C:\\tmp\\new.txt", "relpath": "docs/new.txt" },
    { "src_path": "C:\\tmp\\logo.png" }
  ]
}

# Response
{
  "status": "ok",
  "added": 2,
  "files": [ ... ]
}

11. Request Headers Reference

Complete reference of HTTP headers used by the KJK API.

KJK API 使用嘅 HTTP 標頭完整參考。

KJK API 使用的 HTTP 标头完整参考。

HeaderTypical ValueRequiredDescription
Content-Type application/octet-stream
application/json		 Required Determines how the server parses the request body. Use application/octet-stream for binary file uploads, application/json for JSON payloads.
User-Agent KJK-Client/1.0 Optional Identifies the client application. Useful for logging and debugging. Any string is accepted.
Accept application/json
application/octet-stream		 Optional Hint to the server about the desired response format. The format query parameter takes precedence.
Authorization — Optional Not used. Authentication is via the password query parameter or JSON body field.
Why no Authorization header? The KJK API uses password-based encryption, not HTTP authentication. The password is passed as a query parameter or in the JSON body, and is used to encrypt/decrypt the data — not to authenticate the HTTP request.
點解冇 Authorization 標頭? KJK API 用嘅係基於密碼嘅加密,唔係 HTTP 認證。密碼以查詢參數或 JSON 主體欄位傳遞,用嚟加密/解密資料 — 唔係用嚟認證 HTTP 請求。
为什么没有 Authorization 标头? KJK API 使用基于密码的加密,而非 HTTP 认证。密码作为查询参数或 JSON 体字段传递,用于加密/解密数据 — 而不是用于认证 HTTP 请求。

13. Full Workflow Examples

Complete Bash Script (Linux / macOS)

A full script that encrypts a file, decrypts it back, and verifies the result.

一個完整嘅腳本,加密檔案、解密返,並驗證結果。

一个完整的脚本,加密文件、解密回来,并验证结果。

bash 
#!/bin/bash
# KJK Encryptor - Full workflow example
# Usage: ./kjk_workflow.sh myfile.txt

SERVER="http://127.0.0.1:5000"
INPUT="$1"
PASSWORD="mypassword"

if [ -z "$INPUT" ]; then
  echo "Usage: $0 <file>"
  exit 1
fi

echo "=== 1. Check server status ==="
curl -s "$SERVER/status" -H "User-Agent: KJK-Client/1.0"
echo ""

echo "=== 2. Encrypt file ==="
curl -X POST "$SERVER/encrypt?password=$PASSWORD&filename=$(basename "$INPUT" .txt)&ext=txt" \
  --data-binary @"$INPUT" \
  -H "Content-Type: application/octet-stream" \
  -H "User-Agent: KJK-Client/1.0" \
  -o "encrypted.kjk"
echo "Encrypted to: encrypted.kjk"

echo "=== 3. Decrypt file ==="
curl -X POST "$SERVER/decrypt?password=$PASSWORD" \
  --data-binary @encrypted.kjk \
  -H "Content-Type: application/octet-stream" \
  -H "User-Agent: KJK-Client/1.0" \
  -o "decrypted.txt"
echo "Decrypted to: decrypted.txt"

echo "=== 4. Verify ==="
if diff -q "$INPUT" "decrypted.txt" >/dev/null; then
  echo "✅ Success: files match!"
else
  echo "❌ Error: files differ!"
fi

Complete PowerShell Script (Windows)

The same workflow in PowerShell for Windows users.

同樣嘅工作流程,PowerShell 版本,畀 Windows 用戶。

相同的工作流程,PowerShell 版本,供 Windows 用户使用。

powershell 
# KJK Encryptor - Full workflow example (Windows PowerShell)
# Usage: .\kjk_workflow.ps1 myfile.txt

param(
    [Parameter(Mandatory=$true)]
    [string]$InputFile
)

$Server = "http://127.0.0.1:5000"
$Password = "mypassword"
$Headers = @{ "User-Agent" = "KJK-Client/1.0" }

Write-Host "=== 1. Check server status ===" -ForegroundColor Cyan
$status = Invoke-RestMethod -Uri "$Server/status" -Method GET -Headers $Headers
Write-Host "Server: $($status.name) v$($status.version)"

Write-Host "`n=== 2. Encrypt file ===" -ForegroundColor Cyan
$bytes = [System.IO.File]::ReadAllBytes($InputFile)
$baseName = [System.IO.Path]::GetFileNameWithoutExtension($InputFile)
$ext = [System.IO.Path]::GetExtension($InputFile).TrimStart(".")
$encUrl = "$Server/encrypt?password=$Password&filename=$baseName&ext=$ext"
Invoke-RestMethod -Uri $encUrl `
    -Method POST `
    -ContentType "application/octet-stream" `
    -Headers $Headers `
    -Body $bytes `
    -OutFile "encrypted.kjk"
Write-Host "Encrypted to: encrypted.kjk"

Write-Host "`n=== 3. Decrypt file ===" -ForegroundColor Cyan
$decBytes = [System.IO.File]::ReadAllBytes("encrypted.kjk")
Invoke-RestMethod -Uri "$Server/decrypt?password=$Password" `
    -Method POST `
    -ContentType "application/octet-stream" `
    -Headers $Headers `
    -Body $decBytes `
    -OutFile "decrypted.txt"
Write-Host "Decrypted to: decrypted.txt"

Write-Host "`n=== 4. Verify ===" -ForegroundColor Cyan
$origHash = (Get-FileHash $InputFile).Hash
$decHash = (Get-FileHash "decrypted.txt").Hash
if ($origHash -eq $decHash) {
    Write-Host "✅ Success: files match!" -ForegroundColor Green
} else {
    Write-Host "❌ Error: files differ!" -ForegroundColor Red
}

Python Example

Using Python's requests library for cross-platform compatibility.

使用 Python 嘅 requests 程式庫,跨平台兼容。

使用 Python 的 requests 库,跨平台兼容。

python 
import requests

SERVER = "http://127.0.0.1:5000"
HEADERS = {"User-Agent": "KJK-Client/1.0"}

# 1. Check status
resp = requests.get(f"{SERVER}/status", headers=HEADERS)
print("Status:", resp.json())

# 2. Encrypt a file
with open("myfile.txt", "rb") as f:
    data = f.read()
resp = requests.post(
    f"{SERVER}/encrypt",
    params={"password": "mypassword", "filename": "myfile", "ext": "txt"},
    data=data,
    headers={**HEADERS, "Content-Type": "application/octet-stream"},
)
with open("encrypted.kjk", "wb") as f:
    f.write(resp.content)
print("Encrypted to encrypted.kjk")

# 3. Decrypt the file
with open("encrypted.kjk", "rb") as f:
    enc_data = f.read()
resp = requests.post(
    f"{SERVER}/decrypt",
    params={"password": "mypassword"},
    data=enc_data,
    headers={**HEADERS, "Content-Type": "application/octet-stream"},
)
with open("decrypted.txt", "wb") as f:
    f.write(resp.content)
print("Decrypted to decrypted.txt")
